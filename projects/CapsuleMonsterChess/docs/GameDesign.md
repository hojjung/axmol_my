# 캡슐 몬스터 체스 기획 기준

## 한 줄 정의

세로형 모바일 idle auto battler다. 덱을 성장시키고 TFT식 육각 전투를 반복해 파밍하며,
비동기 PvP 주간 랭킹 보상을 얻는다.

## 사용자 흐름

1. 타이틀 화면에서 CDN 버전 manifest와 필수 콘텐츠를 확인한다.
2. 클라이언트·규칙 버전이 서버와 다르면 로그인 전에 업데이트를 요구한다.
3. Firebase 로그인 후 프로필, 재화, 덱과 인벤토리를 표시한다.
4. Clash Royale 방식의 유닛 도감·카드형 인벤토리에서 덱을 편성한다.
5. 유닛 업그레이드, 레벨업, 장비 탈착으로 덱을 성장시킨다.
6. 스토리, 아이템 던전, 특수 던전, PvP 중 하나를 선택한다.
7. 육각 보드 오토배틀을 재생하고 보상을 받아 다시 성장한다.

## 콘텐츠

- 스토리: 1,000개 이상 확장 가능한 스테이지. 로컬 시뮬레이션을 허용한다.
- 아이템 던전: 피로도를 사용해 성장 재료와 장비를 획득한다.
- 특수 던전: 시즌 규칙과 별도 보상을 제공한다.
- PvP: 방어 덱/고스트 덱 기반 비동기 전투와 주간 MMR 랭킹. 서버 판정만 유효하다.
- 역할군: Pawn, Knight, Bishop, Rook, Queen, King.
- 속성: 불, 물, 풀, 빛, 어둠.
- 성장: 영속 성장, 장비, 3단 진화와 덱 조합을 중심으로 한다.

## 경제와 지갑

향후 인앱 결제와 PvP 보상에 체인 토큰을 연결한다. 구매분 중 30%를 DAO 보상 풀에 넣고,
주간 랭킹에 비례해 유저 지갑으로 분배하는 것이 장기 핵심 구조다.

현재 단계에서는 Monad, Solana 등 특정 체인을 선택하거나 SDK를 넣지 않는다. 게임 원장과
지갑 연결 인터페이스를 분리해 체인을 교체할 수 있어야 하며, PvP 결과·MMR·보상·원장 기록은
항상 서버 권위로 확정한다.
